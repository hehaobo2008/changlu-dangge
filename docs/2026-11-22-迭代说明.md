# 2026-11-22 迭代说明：外婆的旧册子

这一轮把全片统一到一个设定上：**2049 年登船去月球之前，宁宁翻开外婆留下的旧册子**。每一幕是册子里的一张“照片”，五张纸本来就夹在册子里，结尾册子摊开成立体书，再合上。全片由宁宁讲述。

迭代前的源码与文档已打包备份在 `../_备份_迭代前_2026-11-22/changlu-dangge-src-docs.tar`。

## 二、文件改动

新增：

- `src/story.js`：全部新增文案（扉页、时间戳、字幕、间章、纸签、结尾），文案同学只需要改这一个文件。
- `src/narration.js`：扉页、字幕、间章、纸签、结尾立体书的界面逻辑，只操作 DOM，不动三维场景。
- `src/album_images.js`：结尾立体书用的五座岛（从总览视角渲染后抠图的 WebP，以 data URL 内嵌，所以打包脚本不需要改）。

## 三、自动化测试与录屏

- 自动化浏览器（Playwright 等，`navigator.webdriver` 为真）和 `?capture=1` 会跳过扉页、跳过结尾立体书，以免影响原有 478 项检查。想在自动化里看扉页和立体书，地址加 `?title=1`。
- `tools/render_video.mjs` 的演示片是脚本化镜头和自带字幕，**不会**自动带上这轮的扉页、字幕、间章和立体书。建议这次直接用录屏软件录制真实体验（开自动漫游即可），或另行更新该脚本。

## 四、本地构建

在项目根目录照常运行：

```
npm run build
npm run serve
```

然后打开 http://127.0.0.1:8137/ 。
